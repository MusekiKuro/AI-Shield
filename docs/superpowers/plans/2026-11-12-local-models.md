# Локальные модели: Gemma 4 12B и Whisper turbo

Дата: 12 ноября 2026. Дедлайн проекта: 21 ноября 2026.

Контракты, размещение, уровни агентов и календарь — в [ARCHITECTURE.md](../../ARCHITECTURE.md). Здесь только карточки задач M и порядок запусков на ПК.

## Цель

Заменить облачные сервисы локальными моделями и получить измеренную таблицу качества для защиты. Текстовый MVP модели не ждёт: без них работает словарь.

## Решения

- **Основная модель:** Gemma 4 12B (`google/gemma-4-12B-it`), дообучение QLoRA через Unsloth, запуск в GGUF Q4 через llama-server.
- **Запасная модель:** уже скачанная Qwen 4B через Ollama на ноутбуке. Она же — строка сравнения в таблице.
- **Третий кандидат:** Sherkala-8B. Подключается, только если Gemma 4 провалит казахский на M10.1. Лицензия некоммерческая.
- **Распознавание:** Whisper turbo без дообучения. Для казахского — готовая версия ISSAI (`issai/whisper-turbo`).
- **Дообученная модель идёт в демо, только если замер показывает прирост** (правило выбора в M10.3). Иначе остаётся исходная Gemma 4 с подсказкой.

Железо: Windows, Core Ultra 7 265KF, 32 ГБ ОЗУ, RTX 5080 16 ГБ, 1 ТБ. Доступ разрешён администрацией университета.

## Формат записи диалога

Один диалог — одна строка JSON. Формат общий для обучающих пакетов M04 и тестового набора M05.

~~~json
{"id": "ru-01-001", "language": "ru", "synthetic": true, "kind": "fraud", "segments": [{"speaker": "caller", "text": "Здравствуйте, служба безопасности банка."}, {"speaker": "customer", "text": "Слушаю."}, {"speaker": "caller", "text": "Срочно переведите все средства на безопасный счёт и никому не говорите."}], "request_seq": 3, "target": {"scheme": "bank_security", "active_request": true, "urgency": true, "secrecy": true, "safe_account_request": true, "evidence": ["переведите все средства на безопасный счёт"]}}
~~~

| Поле | Правило |
|---|---|
| `id` | `<язык>-<номер пакета>-<номер в пакете>`, в тесте — `test-<номер>` |
| `language` | `ru` \| `kk` \| `mixed` |
| `kind` | `fraud` — мошенничество; `normal` — обычный разговор; `hard_normal` — обычный разговор с опасными на вид словами |
| `segments` | От 4 до 14 реплик; `speaker`: `caller` \| `customer` |
| `request_seq` | Номер реплики (с 1), где впервые звучит мошенническая просьба; для `normal` и `hard_normal` — `null` |
| `target` | Точно по [ARCHITECTURE.md, раздел 4.2](../../ARCHITECTURE.md), оценка всего диалога |

Для `normal` и `hard_normal`: `scheme=none`, `active_request=false`, `safe_account_request=false`, `evidence=[]`. `urgency` и `secrecy` ставятся по факту.

Каждый фрагмент `evidence` дословно скопирован из одной реплики.

Только выдуманные имена, без настоящих телефонов, счетов и названий банков.

**Зависимости:** нет. **Файлы:** `ml/README.md`, `ml/requirements.txt`.

- [ ] ПК работает на Windows. Обучение и сборка данных — в WSL2 (Ubuntu): драйвер NVIDIA с поддержкой WSL, Python, Unsloth. Серверы моделей — в самой Windows: готовая сборка llama.cpp с CUDA, Python с PyTorch CUDA для сервера STT.
- [ ] Где лежат файлы: проект и данные доступны из обеих сред; готовый GGUF из WSL2 копируется в папку Windows для llama-server.
- [ ] Скачивание: `google/gemma-4-12B-it` для обучения, `unsloth/gemma-4-12b-it-GGUF` (Q4) для запуска, `openai/whisper-large-v3-turbo`, казахский Whisper.
- [ ] Команда запуска llama-server: порт 8080, имя модели `gemma-4-12b-shield`, ключ, все слои на видеокарте, контекст 8192.
- [ ] Команда запуска сервера STT: порт 8081, ключ, переменные из ARCHITECTURE 5.2.
- [ ] Закрытая сеть до ноутбука через Tailscale и значения `LLM_BASE_URL`, `STT_BASE_URL` для `.env` приложения.
- [ ] Запасная модель: запуск Qwen 4B в Ollama на ноутбуке и значения `LLM_FALLBACK_*`.
- [ ] Порядок шагов M10 с точными командами.

**Готово:** человек без опыта проходит от чистого ПК до двух отвечающих серверов, копируя команды по порядку. Версии и флаги сверены с текущей документацией Unsloth и llama.cpp; то, что сверить не удалось, помечено «проверить при запуске».

### M04. Пакеты обучающих диалогов — L1 для ru, L2 для kk и mixed

**Зависимости:** нет. **Файл пакета:** `data/training/raw/<язык>-<nn>.jsonl`. Один пакет — одно поручение — один файл.

24 пакета: `ru-01`…`ru-08`, `kk-01`…`kk-08`, `mixed-01`…`mixed-08`. В каждом 50 диалогов: 20 `fraud`, 15 `normal`, 15 `hard_normal`.

| Номер пакета | Тема для `fraud` и `hard_normal` |
|---|---|
| 01 | «Служба безопасности банка», безопасный счёт |
| 02 | «Полиция», «следователь», код из SMS |
| 03 | «Техподдержка», программа удалённого доступа |
| 04 | Родственник в беде: авария, больница |
| 05 | «Мама, у меня новый номер», срочный долг |
| 06 | Инвестиции и гарантированный доход |
| 07 | Маркетплейс: предоплата, «курьер», ссылка на оплату |
| 08 | Все схемы вперемешку, длинные диалоги по 10–14 реплик |

- [ ] `hard_normal` зеркалит тему пакета без обмана: настоящий звонок из банка без просьбы о переводе, сын просит денег на общежитие, клиент рассказывает, как ему звонили мошенники, клиент отказывает и кладёт трубку.
- [ ] `normal` — бытовые разговоры о деньгах: возврат долга, коммунальные платежи, покупка, подарок.
- [ ] Диалоги различаются началом, возрастом и тоном собеседников, суммами, длиной. Разговорная речь, а не канцелярит.
- [ ] `kk`: естественный казахский. `mixed`: живое переключение между казахским и русским внутри реплик, как в речи Алматы и Астаны.
- [ ] В пяти диалогах `fraud` каждого пакета клиент сопротивляется, но собеседник продолжает давить: `active_request=true`.

**Готово:** в файле ровно 50 строк, каждая — валидный JSON по формату выше, соотношение видов 20/15/15, каждый `evidence` найден в тексте своей записи дословно. В сообщении исполнителя — список фраз на казахском, в которых он не уверен.

## Риски

- **Казахский язык.** Качество Gemma 4 12B и Whisper неизвестно до M10.1. Запасной путь: Sherkala-8B для казахского, словарь для остального.
- **Сгенерированные данные однообразны.** Модель может выучить стиль генератора, а не признаки. Защита: тест пишут люди; темы пакетов разведены; `hard_normal` обязателен.
- **Модель на защите.** ПК в зал не принести. Основной путь — закрытая сеть до ПК, запасной — Qwen 4B на ноутбуке, последний — записанный ролик.
- **Время.** Модели не должны отнять больше трёх дней у приложения. Агенты пишут скрипты параллельно с волнами 0–1; запуски идут в фоне.
